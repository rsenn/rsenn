What each file does

All optional. Leave a key out and that feature is simply absent.

01

logo.svg

Inlined into the header, so it follows the theme colours and light/dark.

02

decor.svg

Sprites for bullets, horizontal rules and button frames.

03

wallpaper.svg + .js

Groups of shapes behind the page; the script moves them.

04

dotmatrix.svg

One cell per character; drawn wherever the site asks for the font.

Bullets come from decor.svg

  • Tinted — single-colour art takes the accent colour, in light and dark.
  • Sized — relative to the text, so it scales with the font.
  • Optional — no bullet symbol, no change.
