# Retired mascot artwork (shish)

The cream/teal mascot theme (Gemini concept sheets, cut-out sprites, animated
wallpaper, bestiary page) was retired when the shish site went monochrome.
Nothing here is read by the build. To bring it back: move the files to `../art/`,
restore the `art.wallpaper/decor/assets/logo` keys and the Bestiary page in
`site.config.js`, and re-run `python3 make-sprites.py` if sprites change.
